# Passer de React pur à Next.js App Router : le bilan sans détour

J'ai failli saboter Onixe par simple entêtement.

On avait commencé le développement sur React pur. C'était ma zone de confort. Je maîtrisais les hooks, le state management client, le build Vite.

Tout le monde me parlait de Next.js App Router et des Server Components. J'ai refusé d'écouter pendant trois mois. Changer d'architecture en plein chantier me paraissait être un suicide en termes de timing.

Et avec le recul, c'est cette résistance qui a failli devenir notre plus grand frein.

On a fini par migrer.

Trois semaines de refactoring intense.

Le résultat un mois plus tard :
- Un temps de chargement initial divisé par trois.
- Une sécurité renforcée grâce aux Server Actions qui ne fuient aucun secret côté client.
- Un routing évident et une structure de code que même nos agents IA comprennent sans ambiguïté.

S'accrocher à un choix technique juste parce qu'on a déjà investi du temps dedans est le piège le plus coûteux en dev.
