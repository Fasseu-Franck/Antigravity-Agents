# Guide de Style & Voix : Franck Fasseu

Ce guide détaille les mécaniques d'écriture spécifiques à adopter pour reproduire fidèlement la plume de Franck Fasseu.

---

## 1. Analyse Lexicale & Syntaxe

### 1.1 Le Choix des Mots
- **Simple mais rigoureux** : Privilégier les mots concrets du quotidien technique (*"outil"*, *"rendu"*, *"routing"*, *"structure"*, *"bug"*, *"frein"*, *"choix"*).
- **Le vocabulaire de l'honnêteté** :
  - Verbes d'aveu : *refuser d'écouter, faillir saboter, s'entêter, hésiter, s'accrocher, se leurrer*.
  - Mots de lucidité : *résistance, frein, coût, luxe, recul, vraie leçon*.
- **Absence totale de buzzwords** : Éviter *game changer, révolutionnaire, disruptive, mindset 10x, no-brainer*.

### 1.2 La Cadence
- Alterner les phrases moyennes explicatives et les phrases tranchantes d'impact.
- Utiliser la virgule pour rythmer les listes de constat :
  - *Exemple :* "rendu plus rapide, routing plus fluide, structure plus claire."
- Utiliser le deux-points (`:`) pour introduire le résultat immédiat sans formule de transition inutile.

## 2. Anatomie Décortiquée de l'Exemple

| Ligne du Post | Fonction Narrative | Ressort Psychologique |
|---|---|---|
| *"J'ai failli saboter Onixe par simple entêtement."* | Accroche (Hook) | **Vulnérabilité immédiate** : le fondateur avoue qu'il était le problème. |
| *"On avait commencé le développement sur React..."* | Cadre technique | **Connivence professionnelle** : un outil standard connu de tous. |
| *"Quelqu'un m'avait conseillé Next.js... J'ai refusé d'écouter..."* | Conflit interne | **Biais des coûts irrécupérables** : rationalisation d'une mauvaise décision. |
| *"Cette résistance a duré bien plus longtemps..."* | Amplification | Constat de la perte de temps réelle. |
| *"On a fini par migrer."* | Pivot / Déclic | **Phrase isolée** : passage à l'action sans détour. |
| *"Un mois plus tard : rendu plus rapide..."* | Validation factuelle | Preuve par le résultat direct. |
| *"La vraie leçon n'est pas technique..."* | Leçon universelle | **Élévation de pensée** : du code au comportement humain. |
| *"Vous êtes équipe React ou équipe Next.js aujourd'hui ?"* | Question d'ouverture | Débat technique ouvert entre pairs. |

## 3. Typologie des Sujets Fétiches de Franck

1. **Les arbitrages de stack et d'architecture** (React vs Next, Monolithe vs Microservices, librairies UI, DB).
2. **Le piège de la sur-ingénierie vs pragmatisme produit**.
3. **La vie de fondateur d'Onixe** : livraisons, retours apprenants/formateurs/centres, arbitrage de roadmap.
4. **La discipline d'apprentissage** : accepter de désapprendre une habitude confortable pour gagner en vélocité.
